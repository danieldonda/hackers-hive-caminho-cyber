# 🐝 Caminho Cyber — Guia do Aluno

> **Você não precisa saber tudo. Precisa saber o próximo passo.**

Este repositório reúne o material de apoio da masterclass **“O caminho certo para começar em cibersegurança”**, da **Hackers Hive**.

A proposta é transformar excesso de informação em **direção, sequência e execução**.

---

## 🚀 Comece aqui

Você pode usar este material de três formas:

### 1. Ler direto no GitHub
Navegue pelas pastas e abra os arquivos `.md`.

### 2. Baixar tudo como ZIP
No topo deste repositório:

**Code → Download ZIP**

Depois extraia a pasta no seu computador.

### 3. Clonar com Git

```bash
git clone https://github.com/danieldonda/hackers-hive-caminho-cyber.git
cd hackers-hive-caminho-cyber
```

---

## 🧠 Abrindo no Obsidian

Este material foi organizado como um **Vault do Obsidian**.

1. Instale o Obsidian.
2. Clone ou baixe este repositório.
3. Abra o Obsidian.
4. Escolha **Open folder as vault / Abrir pasta como vault**.
5. Selecione a pasta `hackers-hive-caminho-cyber`.
6. Abra:

**`00 - Comece Aqui/🏠 HOME - Caminho Cyber.md`**

A configuração básica do Vault também está incluída na pasta `.obsidian`.

## 🧭 O Método Caminho Cyber

A trilha é sequencial:

```text
1. Redes
   ↓
2. Sistemas Operacionais
   ↓
3. Fundamentos de Segurança
   ↓
4. Especialização
   ↓
5. Prática + Portfólio
   ↓
6. Mercado
```

A ideia não é tentar aprender **toda a cibersegurança**.

É construir uma base sólida e aprofundar o conhecimento na hora certa.

## ⚠️ Uso responsável

Este material é educacional.

Qualquer atividade prática de segurança deve ser feita somente em:

- seus próprios sistemas;
- máquinas virtuais;
- laboratórios;
- plataformas de treinamento;
- ambientes para os quais exista autorização explícita.

**Nunca teste sistemas de terceiros sem autorização.**
