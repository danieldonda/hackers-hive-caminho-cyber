# 🧭 Diagnóstico — Onde Estou Hoje?

⬅ [[🏠 HOME - Caminho Cyber]]

Antes de começar o plano, responda **sem pesquisar**. O objetivo não é tirar nota. É descobrir onde você realmente está.

Marque cada item como:

- ✅ **Sei explicar e fazer sozinho**
- 🟡 **Já vi, mas preciso consultar**
- ❌ **Não sei / nunca fiz**

---

## 1. Redes

- [ ] Explico o que é IP, máscara e gateway
- [ ] Sei a diferença entre TCP e UDP
- [ ] Sei o que é DNS e acompanho uma resolução de nome
- [ ] Leio uma tabela de rotas simples
- [ ] Sei o que significa uma porta aberta
- [ ] Consigo capturar tráfego com Wireshark/tcpdump e identificar uma conexão

### Resultado
- 5–6 ✅ → pode considerar a Etapa 1 atendida
- 3–4 ✅ → revise os pontos amarelos
- 0–2 ✅ → comece em [[1️⃣ Etapa 1 - Redes]]

---

## 2. Sistemas Operacionais

### Linux
- [ ] Navego pelo terminal sem depender de interface gráfica
- [ ] Entendo permissões `rwx`, usuários, grupos e sudo
- [ ] Identifico processos e serviços
- [ ] Sei onde procurar logs

### Windows
- [ ] Entendo usuários, grupos e privilégios
- [ ] Uso Event Viewer para investigar eventos
- [ ] Conheço o básico de PowerShell
- [ ] Explico, em linhas gerais, o que é Active Directory

### Resultado
- 7–8 ✅ → pode considerar a Etapa 2 atendida
- 4–6 ✅ → revise os pontos amarelos
- 0–3 ✅ → comece em [[2️⃣ Etapa 2 - Sistemas Operacionais]]

## 3. Fundamentos de Segurança

- [ ] Explico a tríade CIA com exemplos
- [ ] Diferencio ameaça, vulnerabilidade e risco
- [ ] Explico autenticação × autorização
- [ ] Sei a diferença entre hash e criptografia
- [ ] Entendo por que MFA reduz risco
- [ ] Conheço o propósito do MITRE ATT&CK
- [ ] Consigo analisar um phishing de forma básica
- [ ] Entendo a função de logs e evidências

- 7–8 ✅ → você pode avançar para especialização
- 4–6 ✅ → revise os gaps
- 0–3 ✅ → faça [[3️⃣ Etapa 3 - Fundamentos de Segurança]]
