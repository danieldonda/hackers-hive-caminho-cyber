# 🚀 Como Usar Este Guia

⬅ Voltar para [[🏠 HOME - Caminho Cyber]]

---

## O que este vault é (e o que não é)

**É:** um guia de decisão. Ele responde *"o que eu faço agora?"* todos os dias, por 90 dias.

**Não é:** um curso completo de cibersegurança. Não existe curso completo. Existe **sequência correta**.

> [!tip] A regra de ouro
> Se você abriu este vault e não sabe o que fazer, abra [[📅 Plano de 90 Dias]] e execute o item da semana atual. Só isso.

---

## Instalando (para quem nunca usou Obsidian)

1. Baixe o Obsidian em `obsidian.md` — é gratuito, funciona em Windows, macOS, Linux, Android e iOS.
2. Abra o Obsidian → **"Abrir pasta como vault"**.
3. Selecione a pasta `Caminho Cyber - Guia do Aluno`.
4. Pronto. Nada é enviado para lugar nenhum — os arquivos são seus, em `.md`, no seu computador.

> [!info] Prefere não instalar nada?
> Todos os arquivos são texto simples (Markdown). Você consegue ler tudo no Bloco de Notas, no VS Code ou no GitHub. Só perde os links clicáveis e o mapa visual.

---

## As 4 mecânicas que você precisa conhecer

### 1. 🔗 Links `[[assim]]`
Palavras entre colchetes duplos são **portas**. Clique e você viaja para a nota relacionada. É assim que os conceitos se conectam — do jeito que eles se conectam na vida real.

### 2. 🏷 Tags
Toda nota tem tags no topo (em `tags:`). Elas permitem cortar o material por outro eixo: por etapa, por tipo, por área. Veja o dicionário completo em [[🏷 Mapa de Tags]].

Clique em qualquer tag para ver **todas** as notas com aquela marcação.

### 3. ⬅ Backlinks
No rodapé de cada nota, o Obsidian mostra **quem aponta para ela**. Isso responde a pergunta mais útil do estudo: *"onde mais esse assunto aparece?"*

### 4. 🕸 Graph View (`Ctrl+G` / `Cmd+G`)
O mapa visual do seu conhecimento. No começo ele mostra o **meu** mapa. Conforme você cria suas notas, ele passa a mostrar o **seu**.

## A regra contra dispersão

Se algo interessante aparecer e **não estiver na etapa atual**, faça isso:

1. anote em [[⛔ O Que NÃO Estudar Agora]];
2. coloque uma data para revisitar;
3. volte para a etapa.

Curiosidade é uma qualidade. Sem filtro, vira sabotagem.

---

## Como saber se aprendeu

Não use “assisti” como métrica. Use **evidência**:

- consigo explicar sem consultar?
- consigo reproduzir no laboratório?
- consigo interpretar uma saída, não apenas rodar um comando?
- consigo escrever com minhas palavras?

Se a resposta for não, marque `#status/revisar` e siga o ciclo.
