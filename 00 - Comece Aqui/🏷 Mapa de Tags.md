# 🏷 Mapa de Tags

⬅ [[🏠 HOME - Caminho Cyber]] · [[🚀 Como Usar Este Guia]]

---

As pastas organizam o material por **onde ele mora**. As tags organizam por **o que ele é**. Use as duas coisas — elas se cruzam, e é nesse cruzamento que você acha o que precisa.

Clique em qualquer tag abaixo para ver todas as notas marcadas com ela.

---

Onde o assunto entra na sequência do [[🧠 O Método Caminho Cyber]].

| Tag | Significado | Nota principal |
|---|---|---|

## 📈 Por status — `#status/*`

**Estas são suas.** Edite o `tags:` de cada nota conforme avança. É assim que o vault deixa de ser meu e passa a ser seu.

| Tag | Quando usar |
|---|---|
| `#status/nao-iniciado` | Ainda não cheguei aqui |
| `#status/em-andamento` | Estou nisso agora |
| `#status/concluido` | Domino e sei explicar sem consultar |
| `#status/revisar` | Passei, mas não fixou |

> [!tip] O painel de progresso mais simples do mundo
> Busque `#status/em-andamento`. Se aparecerem mais de **3 notas**, você está disperso. Feche frentes antes de abrir novas.

## Como combinar tags na busca

O Obsidian aceita operadores na barra de busca (`Ctrl+Shift+F`):

```
tag:#etapa/redes tag:#tipo/pratica     → só laboratórios de redes
tag:#area/soc -tag:#status/concluido   → o que falta na trilha de SOC
tag:#duvida                            → sua lista de pendências mentais
```

> [!success] Rotina de domingo
> Busque `#duvida`. Resolva duas. Apague a tag. Toda semana, sua lista de pontos cegos encolhe.
